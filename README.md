# ODP Office

Android-Zentrale für OpenDailyPacks.

## V0.1
- Dashboard
- Bereiche für Bestellungen, Bestand, Versand, Finanzen und Schnittstellen
- GitHub Actions APK-Build

## Zielarchitektur
- Bestellungen aus eBay/Shopify/weiteren Kanälen
- Bestandsabgleich
- Versandlabel + automatische Tracking-Rückmeldung
- Finanzübersicht für Umsatz, Kosten, Gebühren, Wareneinsatz und Liquidität
- Integrationen für Billbee, Finom und Lexware
